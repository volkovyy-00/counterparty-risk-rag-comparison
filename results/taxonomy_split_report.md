# Approach 3: risk-factor split per filing

Corpus `edgar_latest`, window 12,000 characters. Rules: `corpus.split_risk_factors` (plain line rules, no model call). A heading is a line of 6-60 words ending in a period and followed by a longer line; a sub-caption is a short line naming risks ("Risks Related to ..."). A filing with fewer than 8 headings or a section over 3x the window gets the paragraph split (`corpus.split_paragraphs`), else the fixed windows.

**8 of 10 filings split by heading.** Windows sent to the model: 88 with this split vs 83 with the old fixed windows.

Why GM, F use the paragraph split: these 10-Ks set each heading in bold at the start of its first paragraph. The text extraction keeps the words but not the bold, so heading and body share one line. Each paragraph whose first sentence reads like a heading becomes a section with that sentence as its heading. Continuation paragraphs that read the same way become sections too, so these filings split a little finer than the others.
